## 价格差几十倍的原因：线路、带宽口径、计费方式

同样是香港机房，价格差几十倍主要差在四件事上，搞懂这四点，看任何报价单都不会被字面数字迷惑。

**第一是线路。** 大陆用户访问香港服务器，走的是运营商回程线路。普通机器走 163 骨干网，晚高峰拥堵严重；高端机器走电信 CN2、联通 AS9929、移动 CMIN2 这类精品线路，成本高出不少，售价自然也高。这是香港 VPS 价格分层的最大原因。

**第二是带宽类型。** “200M 带宽”和“5M 带宽”哪个贵，答案可能反直觉——阿里云轻量的 200M 是共享性质的峰值带宽，而 ECS 的 5M 固定带宽是独享的，后者单位成本更高。看价格必须同时看带宽是“峰值”还是“固定”，否则对比毫无意义。

**第三是流量计费口径。** 有的商家流量按双向计算（上传+下载都算），有的按单向计算。同样标称 1TB 流量的套餐，单向计费的实际可用量是双向口径的两倍。GoMami 的流量就是单向计算，这点在下单前值得确认清楚，很多低价套餐没写明口径，实际到手流量会打对折。

**第四是硬件。** 同样的线路，配入门级 EPYC 和配 Zen 5 旗舰、5.7GHz 消费级旗舰，价格也不是一个量级。
